В каталоге размещены дополнительные материалы к докладу на конференции DAMDID 2026.

В докладе представлены результатов эксперимента по функциональной разметке терминов, полученных  результате тематического моделирования четырех корпусов коротких текстов:

1. Корпус новостных сообщений  Riavrn.ru (rvr).
2. Корпус новостных сообщений  Moe-online.ru (mor).
3. Корпус отзывов покупателей интернет-площадки Wildberries (wb).
4. Корпус аннотаций научных статей ruSciBench (rsb).
